ARC MAINNET · FILE INTEGRITY

Give a file a checkable timestamp.

Choose a file, calculate its fingerprint in your browser, and anchor that fingerprint to your wallet on Arc. Anyone with the file and your wallet address can check when you recorded it.

01 · PREPARE

Choose a file

Files stay on this device. Only a 32-byte SHA-256 digest goes on chain. Maximum file size: 20 MB.

SHA-256 fingerprintChoose a file to begin
02 · ANCHOR

Record it on Arc

Connect an EVM wallet with a little USDC on Arc for gas. The contract cannot take custody of your file or funds. Your wallet will show the transaction before you approve it.

03 · VERIFY

Check a record

Choose the original file above, then enter the wallet address that anchored it. Reading the chain costs no gas.

What this proves

A matching record shows that a wallet published this digest by the recorded block time. It does not prove who owns the wallet, that a file was delivered, its quality, or that it has not been copied. A hash of an easily guessed file can reveal which file was used.
